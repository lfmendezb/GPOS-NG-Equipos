# Modelo de datos de L1a-4 (persistencia de la licencia): toda la DDL se puede construir ya

- `Licencia.Gracias` (fila cifrada de `dbo.Configuracion`, JSON con `HoraCorte` y `TopeGraciaUtc` null incluido) y `Licencia.CambiosRnc:<empresa>` alineados con el motor del PR #31 sin cambiar su lógica.
- `dbo.Licencias`: `Sha256Contenido` + `Sha256Archivo`, **`AceptadaUtc` separada de `RecibidaUtc`** (necesario para NV-02/NV-07 tras una restauración), `Kids`, `Emitida`; `UX_Licencias_Aceptada` único sobre (`Sha256Contenido`, `NivelFirma`) filtrado, compatible con SEG-L2-24.
